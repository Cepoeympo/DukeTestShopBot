## Известные ограничения

- `sendData` доступен только при запуске из web_app-кнопки бота; из ссылки —
  резервный сценарий с копированием заказа.
- Telegram не отдаёт корзину боту: всё состояние (корзина, избранное) — в
  `localStorage` WebView, очищается вместе с данными Telegram.
- Цены и состав зафиксированы в `data.js`; синхронизации с flamenashop.ru нет.
