# Фламена — витрина в Telegram

Магазин-витрина научной компании «Фламена» (гели, гелевые покрытия, косметика) как
Telegram Mini App: каталог, карточки товаров, избранное, корзина и оформление
заказа, который приходит менеджеру в Telegram.

Не сайт: это страница, которая открывается внутри Telegram (Web App) и живёт на
GitHub Pages. Бот (`bot.py`) — точка входа: кнопка в чате и меню-кнопка чата.

## Что внутри

| Файл | Назначение |
|------|------------|
| `index.html` | Каркас Mini App, SVG-иконки |
| `style.css` | Оформление, темы Telegram (светлая/тёмная), safe-area |
| `app.js` | Вся логика: каталог, фильтры, поиск, шторка товара, корзина, заказ |
| `data.js` | Каталог (13 позиций), категории, FAQ, контакты — единственный источник данных |
| `img/products/` | Фото товаров в WebP (скачаны с flamenashop.ru, ~500 КБ) |
| `bot.py` | python-telegram-bot: `/start`, меню-кнопка, приём заказов, пересылка админу |
| `requirements.txt` | Зависимости бота |
| `deploy/shopbot.service` | Шаблон systemd-юнита |

## Локальный запуск

```bash
python3 -m http.server 8099 --bind 127.0.0.1
# открыть http://127.0.0.1:8099/
```

Вне Telegram приложение тоже работает: тема берётся из системной, а на оформлении
заказа показывает текст заказа с кнопкой «Скопировать».

## Бот

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # вписать BOT_TOKEN и ADMIN_ID
python bot.py
```

Переменные окружения:

| Ключ | Обязательно | Описание |
|------|-------------|----------|
| `BOT_TOKEN` | да | токен от @BotFather |
| `ADMIN_ID` | да | Telegram ID менеджера, кому падают заказы (`/id` в боте) |
| `WEBAPP_URL` | нет | адрес витрины, по умолчанию GitHub Pages этого репозитория |

При старте бот ставит меню-кнопку чата «Витрина» и команды `/start`, `/help`, `/id`.
Заказ приходит как `web_app_data` (JSON), бот пересылает админу читаемое сообщение
и подтверждает клиенту номер заказа вида `ФЛ-261120-2213`.

## Деплой

1. Фронтенд: Settings → Pages → Branch `main`, папка `/ (root)`.
   Адрес: <https://cepoeympo.github.io/DukeTestShopBot/>
2. Бот: `deploy/shopbot.service` → `~/.config/systemd/user/` или системный юнит,
   `WEBAPP_URL` должен совпадать с адресом Pages (только HTTPS — требование Telegram).

## Данные и правки

- Цены, описания, состав и фото — в `data.js`. Правка каталога не требует сборки.
- Юридический дисклеймер («имеются противопоказания…») выводится в каталоге,
  карточках товаров и в разделе «О бренде» — убирать нельзя.
- Заказ отправляется через `Telegram.WebApp.sendData`, лимит 4096 байт: в payload
  идут только id, название, цена, количество и контакты.
